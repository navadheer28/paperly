FUNDAMENTALS OF DBMS  
4.1. INTRODUCTION  
A Database Management System, or DBMS, is a program that controls the data and offers  
an interface to allow users to interact with the database. It makes sure the data is stored,  
5
retrieved, and handled efficiently. DBMS hides the complexity of data storage and  
provides data manipulation tools and administration. MySQL, Oracle, and PostgreSQL are  
examples.  
4.2. CHARACTERISTICS OF DBMS  
BMS offers data abstraction, data independence, and effective data access. It allows  
multiple user environments as well as data security and integrity enforcement. Other  
important features are concurrency control, backup and recovery, and minimized data  
redundancy. These features enhance DBMS compared to legacy file systems.

4.3. DATA MODEL  
A data model specifies the structure, storage, and manipulation of data in a DBMS. It  
serves as a template for database design. Some popular data models are hierarchical,  
network, relational, and object-oriented models. The most popular one is the relational  
model, which presents data in the form of tables (relations).  
4.4. THREE-SCHEMA ARCHITECTURE  
This structure isolates the database into three levels: internal, conceptual, and external.  
The internal level is concerned with physical storage, the conceptual level is concerned  
with describing the logical structure, and the external level gives user-specific views. This  
isolation enhances data abstraction and independence.  
4.5. COMPONENT MODULES OF DBMS  
DBMS consists of some essential components: the Query Processor, Storage Manager,  
Transaction Manager, and Metadata Manager. They manage query execution, storage of  
data, transaction management, and schema definitions. Collectively, they facilitate  
efficient and safe data operations.
